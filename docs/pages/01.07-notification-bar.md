# Notification Bar

The Notification Bar allows the application to display a single error, warning, success or info message to the user, in a bar at the top of the canvas. It is useful for messages that need the user's attention while they are working on the flow.

<img src="../assets/cc-notification-bar.png" width="900" />

The bar is displayed over the top of the flow editor, below the toolbar, and does not overlap any of the [panels](01.10-panels.md) around the canvas. No bar is displayed by default. The application controls when the bar is displayed and what it contains. See [Notification Bar Config](03.02.04-notification-bar-config.md) for how to do this.

!!! note
    The notification bar is different from the [notification panel](01.06-notification-panel.md). The notification panel is opened from a toolbar button and can contain many messages. The notification bar displays one message and is always visible while it is shown.

## Kinds of notification

The icon and color of the bar depend on the kind of notification: error, info (the default), info-square, success, warning or warning-alt.

## Content

The bar always displays a title and can, optionally, display a subtitle after it. The application can also provide extra content to be displayed in the bar.

## Action button

The bar can include an action button, for example "Retry", that lets the user respond to the message directly.

## Close button

The bar can include a close button. It is only displayed if the application wants to handle the user closing the bar. Common Canvas does not remove the bar itself when the close button is clicked; the application decides what happens.

## Accessibility

The notification bar is announced to screen readers when it is displayed.

* Error notifications are announced immediately, using the `alert` role.
* Other kinds are announced after a short delay, using the `status` role, so that screen readers can detect the change.
* The announcement is repeated whenever the kind, title or subtitle changes.

Because a new notification can replace an old one before the full message is read, a history of notifications should be kept somewhere for screen reader users to review, such as the [notification panel](01.06-notification-panel.md). The application can also provide additional text that is only available to screen readers.

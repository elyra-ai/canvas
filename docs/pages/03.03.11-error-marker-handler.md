# Error Marker Handler

This is an optional handler you don't need to implement unless you want to. This callback allows your code to override the default error/warning marker icon displayed on nodes when they have messages.


## errorMarkerHandler
```js
    errorMarkerHandler(node)
```

The `errorMarkerHandler` callback, when provided, is called for each node that has validation or status messages. The `node` object parameter contains all the attributes of the current node.

This callback should return **a React element** (e.g. `<WarningAltFilled className="d3-error-circle" />`) representing the custom component or icon to display.

If `null`, `undefined` or `void` is returned, Common Canvas will use the default error or warning icons and styling.

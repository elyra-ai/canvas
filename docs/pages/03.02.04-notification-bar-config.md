# Notification Bar Config object

The Notification Bar Config object specifies the content of the [notification bar](01.07-notification-bar.md). It is passed to Common Canvas using the `notificationBarConfig` prop of the `<CommonCanvas>` React object. If the prop is `null` or `undefined` (the default), no bar is displayed. To remove the bar, set the prop back to `null`.

The Notification Bar Config object looks like this:
```js
    const notificationBarConfig = {
       title: "Save failed",
       subtitle: "Your changes could not be saved.",
       kind: "error",
       actionButtonLabel: "Retry",
       onActionButtonClick: () => { console.log("Retry clicked"); },
       onCloseButtonClick: () => { console.log("Close clicked"); },
       screenReaderText: "The flow was not saved. Select Retry to try again."
    };
```

* **title** - String to display as the title of the notification.

* **subtitle** - String to display after the title.

* **kind** - The type of notification. It can be one of: "error", "info", "info-square", "success", "warning" or "warning-alt". If not set, it will default to "info".

* **actionButtonLabel** - Label for an optional action button displayed in the notification.

* **onActionButtonClick** - A callback function that is called when the action button is clicked.

* **onCloseButtonClick** - A callback function that is called when the close button is clicked. The close button is only displayed if this function is provided. Common Canvas does not remove the bar when the close button is clicked, so the application should set the `notificationBarConfig` prop to `null` in this callback.

* **content** - An optional React node containing extra content to display in the notification.

* **screenReaderText** - A string that is only available to screen readers. It is added to the notification and is not displayed visually.

If any of `content`, `actionButtonLabel` or `onActionButtonClick` are specified, the notification is displayed with an action area. Otherwise, a simpler notification is displayed.

### Updating the notification bar

The application can change the bar by passing a new `notificationBarConfig` object to `<CommonCanvas>`. This example displays a bar that is removed when the user closes it:

```js
    const [notificationBarConfig, setNotificationBarConfig] = useState({
        title: "This flow is read-only",
        kind: "info",
        onCloseButtonClick: () => setNotificationBarConfig(null)
    });

    return (
        <CommonCanvas
            canvasController={canvasController}
            notificationBarConfig={notificationBarConfig}
        />
    );
```

### Accessibility

Use `screenReaderText` to give screen reader users additional information that is not shown on the screen. For example, "See notification details in the notifications panel in the toolbar" tells users where to find the history of notifications. See the [Notification Bar](01.07-notification-bar.md#accessibility) page for how the bar is announced to screen readers.

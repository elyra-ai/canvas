## Sub-folders

### `consumers/`

A curated knowledge base for **people building applications with `@elyra/canvas`** — not for contributors to this repository.

Copy the `consumers/` folder into your project (or paste individual files into your AI chat) and tell your AI: _"I am building a canvas app with @elyra/canvas. Use these context files."_

See [`consumers/README.md`](./consumers/README.md) for full details.
